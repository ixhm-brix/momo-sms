# Contributing

## Branches

Never commit directly to `main`. Branch from `main`:

```
<type>/<short-description>
```

Types: `feat`, `fix`, `docs`, `chore`, `test`

Examples: `feat/xml-parser`, `docs/architecture-diagram`, `chore/gitignore`

## Commits

```
<type>: <what changed, imperative mood>
```

Examples:
- `feat: add category rules for airtime and withdrawals`
- `docs: add architecture diagram and README section`

## Pull requests

1. Push your branch and open a PR against `main`.
2. Describe what changed and link the Trello card.
3. One teammate reviews and approves before merge.
4. Delete the branch after merge.

## Definition of done

- Code runs without errors on a clean clone
- README updated if setup or usage changed
- Trello card moved to Done
